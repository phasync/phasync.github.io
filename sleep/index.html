    sleep Function

    Suspends the current coroutine for $seconds seconds, letting the others run.

    Description

    function sleep(float $seconds = 0.0): void

    The same as phasync::sleep, under the name of the native function: with use function phasync\sleep; in a file, its sleep() calls wait without blocking the process. The native sleep() takes whole seconds; this takes a float. Outside a coroutine it blocks, as usleep() does.

    use function phasync\sleep;

phasync::run(function () {
    phasync::go(fn() => print("tick\n"));
    sleep(0.5);                        // the coroutine above runs meanwhile
});

    Defined in phasync\sleep, package phasync/phasync.

    Parameters

    $seconds float default 0.0
    how long to wait; 0 or less only lets the other coroutines run first

    Return values

    No value is returned.

    See also
