    ResponderInterface Interface

    What sends the application's response in the protocol the request arrived in.

    Description

    interface ResponderInterface

    It is the connection (HTTP) or the request (FastCGI) of a server. Dispatcher::dispatch calls it with the application's response.

    final class Echoing implements ResponderInterface
{
    public function respond(ServerRequestInterface $request, ResponseInterface $response): mixed
    {
        echo $response->getStatusCode(), "\n";   // a protocol would write the response to its client

        return $response->getStatusCode();
    }
}

    Defined in Swerve\ResponderInterface, package phasync/swerve.

    Methods

    • ResponderInterface::respond Send $response, the answer to $request, and return once its body is sent.
