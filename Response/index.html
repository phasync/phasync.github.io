    Response Class

    A PSR-7 response.

    Description

    class Response implements ResponseInterface, MessageInterface

    Immutable, as PSR-7 requires: the with...() methods return a modified copy. The reason phrase defaults to the standard one for the status code (Response::PHRASES). The body is made with StreamFactory::create.

    $response = new Response(404, ['Content-Type' => 'text/plain'], 'Not found');
$response->getStatusCode();       // 404
$response->getReasonPhrase();     // "Not Found"
$stream = new UnbufferedStream();
$response = $response->withBody($stream);

    Defined in phasync\Psr\Response, package phasync/phasync.

    • Response::__construct Creates a response.
    • Response::getStatusCode Gets the response status code.
    • Response::withStatus Return an instance with the specified status code and, optionally, reason phrase.
    • Response::getReasonPhrase Gets the response reason phrase associated with the status code.
    • Response::getProtocolVersion Retrieves the HTTP protocol version as a string.

    • Response::getHeaders Returns the message headers.
    • Response::hasHeader Checks if a header exists by the given case-insensitive name.
    • Response::getHeader Retrieves a message header value by the given case-insensitive name.
