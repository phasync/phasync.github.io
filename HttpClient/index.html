    HttpClient Class

    A PSR-18 HTTP client that runs concurrent requests on curl_multi.

    Description

    final class HttpClient implements ClientInterface

    get(), post(), put(), request() and sendRequest() return a CurlResponse at once. The transfer starts when its status, headers or body is first read, and every request created up to then starts together. Inside a coroutine only the reading coroutine is suspended; outside one, the reading call blocks until the response has arrived. An HTTP error status such as 404 or 500 is a normal response and throws nothing.

    use phasync\HttpClient\HttpClient;

$client = new HttpClient(['timeoutMs' => 5000]);

// Neither transfer has started yet, so both run at the same time once the first is read.
$a = $client->get('https://example.com/a');
$b = $client->get('https://example.com/b');

echo $a->getStatusCode(), "\n";
echo $b->getBody();

    Cancelling a coroutine that is waiting for a response throws phasync\CancelledException in it. The client stays usable.

    Defined in phasync\HttpClient\HttpClient, package phasync/http-client.
