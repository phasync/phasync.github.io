    HttpClient::sendRequest Method

    Send a PSR-7 request with the client's default options.

    Description

    public HttpClient::sendRequest(RequestInterface $request): ResponseInterface

    The request's Cookie and User-Agent headers replace the cookie and userAgent options, and the other headers are sent as they are. A body that implements MultipartStreamInterface also sets the Content-Type header. The response is returned before its transfer has started.

    A failed transfer (connection refused, DNS failure, timeout, too many redirects) throws a \RuntimeException from the response's getStatusCode(), not from here, and not a PSR-18 ClientExceptionInterface. The exception code is cURL's error number.

    use phasync\Psr\Request;

$response = $client->sendRequest(Request::create('GET', 'https://example.com/'));
echo $response->getStatusCode();
