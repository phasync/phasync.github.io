    HttpClient::get Method

    Send a GET request.

    Description

    public HttpClient::get(
    UriInterface|string $url,
    HttpClientOptions|array|null $options = null
): ResponseInterface

    To send data in the query string, put it in the URL or use request('GET', $url, $data).

    $response = $client->get('https://example.com/search?q=phasync', ['timeoutMs' => 2000]);
$data     = \json_decode((string) $response->getBody(), true);

    Defined in phasync\HttpClient\HttpClient.

    Parameters

    $url UriInterface|string
    The URL to fetch
    $options HttpClientOptions|array|null default null
    Options for this request only

    Return values

    Returns ResponseInterface.

    Errors / Exceptions

    InvalidArgumentException
    For an option name that does not exist
    RuntimeException
    For a headers entry without a colon
