    CacheKeyException Exception

    A key Swerve::cache can't take: PSR-16 keys are non-empty strings without {}()/\@:.

    Description

    final class CacheKeyException extends InvalidArgumentException implements \Stringable, \Throwable, InvalidArgumentException, CacheException

    It is a \InvalidArgumentException and a PSR-16 InvalidArgumentException.

    try {
    Swerve::cache()->get('user:1');          // ':' is not allowed in a key
} catch (CacheKeyException $e) {
    Swerve::cache()->get('user.1');
}

    Defined in Swerve\CacheKeyException, package phasync/swerve.
