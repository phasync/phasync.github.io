    ProtocolUpgrade Class

    A connection that switches from HTTP to another protocol (RFC 9110, section 7.8): the base of WebSocket, and of any protocol of your own.

    Description

    abstract class ProtocolUpgrade

    from() answers the request: with 101 Switching Protocols when the subclass accepts the handshake, or with the subclass's refusal. After the 101, the callback runs in a coroutine of its own, and the connection closes when it returns.

    A subclass implements handshake(), and speaks its protocol with read(), write() and end(); it may override run() to do work around the callback. Application code sees only the subclass's API. The bytes travel on swerve's two streams: the request body is what the client sends after the handshake, the response body what goes back.

    return WebSocket::from($request, function (WebSocket $ws) {
    foreach ($ws as $message) {
        $ws->send("echo: $message");
    }
});

    A protocol of your own:

    final class Shout extends ProtocolUpgrade
{
    protected function handshake(ServerRequestInterface $request): array|ResponseInterface
    {
        return 'shout' === $request->getHeaderLine('Upgrade')
            ? ['Upgrade' => 'shout']
            : new Response(426, ['Upgrade' => 'shout'], 'This address speaks shout');
    }

    public function send(string $line): void
    {
        $this->write(strtoupper($line) . "\n");
    }
}

return Shout::from($request, function (Shout $connection) {
    $connection->send('hello');
});
