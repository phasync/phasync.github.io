    LockInterface Interface

    An object that runs a closure while holding a lock that other coroutines wait for.

    Description

    interface LockInterface
    class Counter implements phasync\Util\LockInterface
{
    use phasync\Util\LockTrait;

    public int $value = 0;
}

phasync::run(function () {
    $counter = new Counter();
    $counter->lock(function () use ($counter) {
        $counter->value++;
    });
});

    Defined in phasync\Util\LockInterface, package phasync/phasync.

    Methods

    • LockInterface::lock Runs $callable while holding the lock of this object, and returns what it returns.

    See also

    • LockTrait Implements LockInterface: a lock that is reentrant for the coroutine holding it and fair for the others.
