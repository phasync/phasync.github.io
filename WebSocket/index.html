    WebSocket Class

    A WebSocket connection (RFC 6455), server side.

    Description

    class WebSocket extends ProtocolUpgrade implements \IteratorAggregate, \Traversable
    return WebSocket::from($request, function (WebSocket $ws) {
    foreach ($ws as $message) {           // ends when the connection closes
        $ws->send("echo: $message");
    }
});

    The callback runs in a coroutine of its own after the handshake; the connection closes when it returns (1000), or throws (1011, and swerve logs the exception). A request that is not a WebSocket handshake is answered 426 or 400.

    One coroutine receives; send() and close() may be called from any. The connection is read all the time, also when the callback only sends: pings from the client are answered, and when the client leaves the callback is cancelled, so a loop such as

    foreach (Swerve::subscribe('news') as $message) {
    $ws->send($message);
}

    ends with its client. The server pings every connection every PING_INTERVAL seconds, from one coroutine for all of them, so proxies don't close a quiet connection.

    Defined in Swerve\Http\WebSocket, package phasync/swerve.

    Constants

    MAX_MESSAGE = 1048576
    The largest message received; a larger one closes the connection with 1009.
    PING_INTERVAL = 15.0
    INBOX = 64
    Messages received and not yet taken by receive(); the reader waits while there are INBOX.

    Methods

    • WebSocket::receive The next text or binary message, or null once the connection is closed: by the client, by close(), because the client broke the protocol, or because swerve drains (a shutdown or reload), which closes it with 1001.
    • WebSocket::getIterator The messages received, until the connection closes.
    • WebSocket::isBinary Whether the message receive() returned last was binary, rather than text.
    • WebSocket::send Send a text message, which must be UTF-8; nothing once the connection is closed.
    • WebSocket::sendBinary Send a binary message; nothing once the connection is closed.
    • WebSocket::close Say goodbye, once: receive() returns null from then on, and the connection closes after the client's own goodbye, or a moment without one.
    • WebSocket::isClosed
