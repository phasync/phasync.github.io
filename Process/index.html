    Process Class

    Starts a child process whose standard streams are used from coroutines without blocking the others.

    Description

    final class Process
    phasync::run(function () {
    $process = phasync\Util\Process::run('echo', ['hello']);

    echo $process->read();                 // hello
    while ($process->isRunning()) {
        phasync::sleep(0.01);
    }
    var_dump($process->getExitCode());     // int(0)
});

    Defined in phasync\Util\Process, package phasync/phasync.

    Methods

    • Process::run Starts $command in the background and returns the object that controls it.

    See also

    • ProcessInterface A child process started with Process::run(), with its standard streams usable from coroutines.
