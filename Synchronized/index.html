    Synchronized Class

    A mutex for coroutines, identified by a string or an object: only one coroutine at a time runs a closure for the same token.

    Description

    final class Synchronized

    Unlike LockTrait, it is not reentrant: asking again from the coroutine that holds the lock throws. Other coroutines wait their turn, also those of the same context, in the order they asked: the holder hands the lock to the first in line.

    phasync::run(function () {
    foreach ([1, 2, 3] as $i) {
        phasync::go(function () use ($i) {
            phasync\Util\Synchronized::run('report', function () use ($i) {
                echo "start $i\n";
                phasync::sleep(0.01);
                echo "end $i\n";           // start and end of different jobs never interleave
            });
        });
    }
});

    Defined in phasync\Util\Synchronized, package phasync/phasync.

    Methods

    • Synchronized::run Runs $closure once no other coroutine runs a closure for $token, and returns what it returns.
