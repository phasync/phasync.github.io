    Request Class

    A PSR-7 outgoing, client-side request.

    Description

    class Request implements RequestInterface, MessageInterface

    The request-target and the URI are independent, as PSR-7 has them: the request-target is the source of truth, and Request::getUri derives a URI from it and the Host header, unless one was set with Request::withUri.

    $request = new Request('POST', '/search?q=phasync', '{"limit":10}', [
    'Host'         => 'example.com',
    'Content-Type' => 'application/json',
]);
(string) $request->getUri();   // "http://example.com/search?q=phasync"

    Defined in phasync\Psr\Request, package phasync/phasync.

    Methods

    • Request::__construct Creates a request.
    • Request::__clone Clones the URI set with withUri(), so a copy does not share it.
    • Request::create Creates a request from a URI, deriving the request-target and Host header from it.
    • Request::getRequestTarget Returns the request target of the message.
    • Request::withRequestTarget Return an instance with the specific request-target.
    • Request::getMethod Retrieves the HTTP method of the request.
    • Request::withMethod Return an instance with the provided HTTP method.
    • Request::getUri Returns the attached URI override, or a URI derived from the request-target plus the Host header.
    • Request::withUri Returns an instance with the provided URI.
    • Request::getQuery The query string from the request target, or from the URI override when one is attached.
    • Request::getProtocolVersion Retrieves the HTTP protocol version as a string.
    • Request::withProtocolVersion Return an instance with the specified HTTP protocol version.
    • Request::getHeaders Returns the message headers.
    • Request::hasHeader Checks if a header exists by the given case-insensitive name.
    • Request::getHeader Retrieves a message header value by the given case-insensitive name.
    • Request::getHeaderLine Retrieves a comma-separated string of the values for a single header.
    • Request::withHeader Return an instance with the provided value replacing the specified header.
    • Request::withAddedHeader Return an instance with the specified header appended with the given value.
    • Request::withoutHeader Return an instance without the specified header.
    • Request::getBody Gets the body of the message.
    • Request::withBody Return an instance with the specified message body.
