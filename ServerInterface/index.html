    ServerInterface Interface

    A protocol server, such as HTTP/1.1 (--http) or FastCGI (--fastcgi).

    Description

    interface ServerInterface

    It turns what arrives on its listener into PSR-7 requests, gives each to the Dispatcher, and sends the response back in its protocol. A worker calls listen(), then run() inside phasync::run(), and drain() when it is to stop.

    $server->listen();                    // throws when the address can't be bound
phasync::run($server->run(...));      // returns once drain() was called and every connection ended

    Defined in Swerve\ServerInterface, package phasync/swerve.

    Methods

    • ServerInterface::listen Open the listener.
    • ServerInterface::run Accept and serve connections until drained.
    • ServerInterface::drain Stop accepting and let the requests in flight finish; ServerInterface::run then returns.

    See also

    • Dispatcher Where a request meets the application, whatever protocol it came in.
    • ResponderInterface What sends the application's response in the protocol the request arrived in.
