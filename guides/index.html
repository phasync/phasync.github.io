    Guides

    Learn by doing: realtime, caching, background work, API calls, processes, production.

    Task-oriented pages that start with working code. A guide solves one problem and links to the reference for every function it uses.

    • Write sequential PHP Placeholder Your handler stays sequential: sleep(), and the other requests are served meanwhile.
    • After the response Placeholder Keep working after the response is sent: send 10,000 e-mails without the client waiting.
    • Realtime: SSE and WebSockets Draft Push to the browser with Server-Sent Events or WebSockets, across all workers.
    • Cache Draft Swerve::cache(): one PSR-16 cache for every worker, read from memory in the worker.
    • Concurrent API calls Placeholder Call several APIs at once and wait for all of them.
    • Running processes Placeholder Run external programs without blocking a worker.
    • Tether Placeholder Interactive components over a WebSocket, written in PHP.
    • Production Placeholder Sizing, reloads, logging, limits and phasync-ext.
