    WaitGroup Class

    Waits until a counted amount of work has been done, like Go's sync.WaitGroup.

    Description

    final class WaitGroup implements SelectableInterface

    Call add() before starting each piece of work, done() when it ends, and await() in the coroutine that waits. await() returns when the counter is zero, and at once if it already is. The counter may be raised again after it reached zero, so one group can be reused.

    phasync::run(function () {
    $group = new phasync\Util\WaitGroup();

    foreach ([0.02, 0.01] as $delay) {
        $group->add();
        phasync::go(function () use ($group, $delay) {
            try {
                phasync::sleep($delay);
            } finally {
                $group->done();
            }
        });
    }
    $group->await();
    echo "both done\n";
});

    Defined in phasync\Util\WaitGroup, package phasync/phasync.

    Methods

    • WaitGroup::isReady Returns true when the counter is zero: nothing is left to wait for.
    • WaitGroup::add Adds $delta to the counter of unfinished work.
    • WaitGroup::done Marks one piece of work as done.
    • WaitGroup::await Waits until the counter is zero.
    • WaitGroup::wait Waits until the counter is zero.

    See also

    • phasync::go Starts $fn as a coroutine in the current context and returns it, without waiting for it.
    • SelectableInterface An object that can be asked whether using it would block, and waited for until it would not.
