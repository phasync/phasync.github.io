    SubscribersInterface Interface

    The subscription point of a publisher: each call to subscribe() makes a reader that receives every later message.

    Description

    interface SubscribersInterface extends \IteratorAggregate, \Traversable

    Iterating over it reads the messages of a new subscription.

    phasync::run(function () {
    phasync::publisher($subscribers, $publisher);

    $subscription = $subscribers->subscribe();
    $publisher->write('first');
    $publisher->close();

    echo $subscription->read();   // first
});

    Defined in phasync\SubscribersInterface, package phasync/phasync.

    Methods

    • SubscribersInterface::subscribe Creates a subscription that receives the messages published after this call.

    See also

    • phasync::publisher Creates a publisher: what is written to $publisher is delivered to every subscription of $subscribers.
    • SubscriberInterface A subscription to a publisher: a reading end that receives every message published after it was made.
