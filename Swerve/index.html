    Swerve Class

    What swerve gives the application: its log, the cache and the messages shared by every worker, and the state of the worker.

    Description

    final class Swerve

    Every method is static. Workers share no memory: the cache and the messages go through the master process, and work once the worker serves, not while swerve.php loads.

    use Swerve\Swerve;

Swerve::log()->info('started');
Swerve::cache()->set('hits', 1, 60);
Swerve::publish('chat', ['user' => 'ann', 'text' => 'hi']);

    Defined in Swerve\Swerve, package phasync/swerve.

    Methods

    • Swerve::log The log of this process: swerve's own PSR-3 logger, in its format (the time, this worker's slot).
    • Swerve::setLog Replace the logger that Swerve::log returns.
    • Swerve::publish Send a message to every subscriber of $topic, in every worker process of this swerve, this one included.
    • Swerve::subscribe Receive what is published to $topic from now on.
    • Swerve::cache The cache every worker shares, held by the master process.
    • Swerve::claim A handle on the name $name, which one holder at a time can hold across the workers.
    • Swerve::draining Whether this worker drains: it is shutting down, reloading or being recycled, and finishes the requests in flight.
    • Swerve::getVersion The installed version, as Composer knows it: 0.1.0-beta1, or dev-main in a checkout.

    See also

    • Cache The cache every worker shares, from Swerve::cache(): a PSR-16 cache held by the master process, the least recently used entries evicted past --cache-size.
    • Claim A handle on a name that one holder at a time can hold across the whole server, from Swerve::claim.
    • Subscription The messages published to a topic, from Swerve::subscribe: iterate over it to receive them.
