    Swerve::subscribe Method

    Receive what is published to $topic from now on.

    Description

    public static Swerve::subscribe(
    string $topic,
    float $maxLag = 30.0,
    ?float $heartbeat = null
): Subscription

    The subscription exists once this returns, not from the first iteration. It ends when its last reference goes, and its loop when the process drains; see Subscription. A subscriber falling more than $maxLag seconds behind gets a SubscriberLagException from the loop. With $heartbeat, the loop also gets null after that many seconds without a message: for a keep-alive.

    foreach (Swerve::subscribe('chat') as $message) {
    echo $message->text, "\n";   // an object arrives as a read-only SealedObject
}

    Defined in Swerve\Swerve.

    Parameters

    $topic string
    what Swerve::publish sent to
    $maxLag float default 30.0
    seconds a message may wait before this subscriber reads it
    $heartbeat ?float default null
    seconds without a message after which the loop yields null; null for never

    Iterate over it to receive the messages Subscription
