    Swerve::setLog Method

    Replace the logger that Swerve::log returns.

    Description

    public static Swerve::setLog(LoggerInterface $log): void

    bin/swerve calls it when a worker starts. An application that embeds swerve without its command line can call it to have log() return its own logger.

    Swerve::setLog(new Monolog\Logger('app'));

    Defined in Swerve\Swerve.

    Parameters

    $log LoggerInterface
    returned by every later call of Swerve::log()

    Return values

    No value is returned.

    See also

    • Swerve::log The log of this process: swerve's own PSR-3 logger, in its format (the time, this worker's slot).
