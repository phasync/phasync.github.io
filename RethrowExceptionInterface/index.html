    RethrowExceptionInterface Interface

    Marks the exceptions that phasync rethrows with a stack trace that begins in the code that called phasync, not inside it.

    Description

    interface RethrowExceptionInterface extends \Throwable, \Stringable

    Implemented by CancelledException, ChannelException and TimeoutException.

    Defined in phasync\RethrowExceptionInterface, package phasync/phasync.

    Methods

    • RethrowExceptionInterface::rebuildStackTrace Replaces the stack trace with one that starts where the exception was rethrown.

    See also

    • CancelledException Thrown in a coroutine whose wait was cancelled with phasync::cancel(), or whose scope failed.
    • ChannelException A channel operation failed: it was written to after it was closed, or the wait looked like a deadlock.
    • TimeoutException A wait with a timeout ran out before it was satisfied.
