    Reference

    Every public class and method, from the source.

    One page per class and per method, at /Class/ and /Class/method: the signature is read from the code, so it cannot drift. Type Swerve::publish in the search box above to go straight there.

    Swerve phasync/swerve

    • Swerve What swerve gives the application: its log, the cache and the messages shared by every worker (see the methods), and the state of the worker.
    • Subscription Messages published to a topic, from Swerve::subscribe(): iterate over it to receive them.
    • Claim A handle on a name that one holder at a time can hold across the whole server, from Swerve::claim().
    • OrderedChannel A topic where every subscriber, in every worker, receives the messages in one and the same order, and each publisher's own messages keep theirs: $ledger = new OrderedChannel('ledger'); $ledger->write(['debit', 12]); foreach ($ledger as $entry) { ...
    • SubscriberLagException A subscription fell further behind its topic than its maxLag, see Subscription.
    • WebSocket A WebSocket connection (RFC 6455), server side.

    phasync phasync/phasync

    • phasync This class defines the essential API for all coroutine based applications.
    • ReadChannelInterface A readable channel provides messages asynchronously from various sources.
    • WriteChannelInterface
    • TimeoutException
    • CancelledException The operation that was being awaited has been cancelled.
    • WaitGroup This class provides an efficient tool for waiting until multiple coroutines have completed their task.
    • RateLimiter This class provides an efficient tool for limiting the rate at which events happen, potentially across coroutines.
    • ProcessRunner Launches and manages a child process on POSIX and Windows alike.

    Other packages

    • HttpClient An asynchronous PSR-18 HTTP client, in the package phasync/http-client.
    • Channel Pass values between coroutines with phasync::channel(): a read waits for a writer, a write into a full channel waits for a reader.

    Advanced

    Channels, wait groups, rate limiters and claims are Advanced: you can build a lot without them.
