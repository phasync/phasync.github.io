    Reference

    Every public class and method, from the source.

    One page per class and per method, at /Class/ and /Class/method: the signature is read from the code, so it cannot drift. Type Swerve::publish in the search box above to go straight there.

    Swerve phasync/swerve

    • Cache The cache every worker shares, from Swerve::cache(): a PSR-16 cache held by the master process, the least recently used entries evicted past --cache-size.
    • CacheKeyException A key Swerve::cache can't take: PSR-16 keys are non-empty strings without {}()/\@:.
    • Claim A handle on a name that one holder at a time can hold across the whole server, from Swerve::claim.
    • Dispatcher Where a request meets the application, whatever protocol it came in.
    • ProtocolUpgrade A connection that switches from HTTP to another protocol (RFC 9110, section 7.8): the base of WebSocket, and of any protocol of your own.
    • Swerve\Http\ServerRequest The PSR-7 request a server gives the application, the same for every protocol.
    • WebSocket A WebSocket connection (RFC 6455), server side.
    • OrderedChannel A topic where every subscriber, in every worker, receives the messages in one and the same order, and each publisher's own messages keep theirs.
    • ProtocolErrorException A peer broke its protocol.
    • ResponderInterface What sends the application's response in the protocol the request arrived in.
    • ServerInterface A protocol server, such as HTTP/1.1 (--http) or FastCGI (--fastcgi).
    • StaticFiles PSR-15 middleware that serves the files of a directory and passes every other request on.
    • SubscriberLagException A subscription fell further behind its topic than its $maxLag seconds, see Subscription.
    • Subscription The messages published to a topic, from Swerve::subscribe: iterate over it to receive them.
    • Swerve What swerve gives the application: its log, the cache and the messages shared by every worker, and the state of the worker.
    • SealedObject A decoded JSON object that nobody can change: what a subscriber of Swerve::subscribe gets for a published object.

    phasync phasync/phasync

    • phasync The static API of phasync: start coroutines, wait for them, cancel them, and wait for streams, flags and contexts.
    • AggregateException Several coroutines failed in one run(), and none of the failures is more important than the others.
    • CancelledException Thrown in a coroutine whose wait was cancelled with phasync::cancel(), or whose scope failed.
    • ChannelException A channel operation failed: it was written to after it was closed, or the wait looked like a deadlock.
    • ContextUsedException A context object was used twice: it was given to run(), go() or withContext() before.
    • ContextFactoryInterface Creates the context of a phasync::withContext() call when the closure first needs it.
    • ExceptionHandlerInterface A context that takes the failures of its coroutines that nobody awaited.
    • SwitchAwareInterface A context that is told when it becomes live and when another does, to swap per-request state in and out.
    • IOException A stream wait failed: the value was no stream, the stream was closed while waited for, or polling failed.
    • PollerInterface Waits for streams on behalf of the event loop.
    • BufferedStream A seekable PSR-7 stream for a body that is still being produced, kept in memory and then in a temporary file.
    • Request A PSR-7 outgoing, client-side request.
    • Response A PSR-7 response.
    • phasync\Psr\ServerRequest A PSR-7 request as a server received it.
    • StreamFactory Builds a PSR-7 stream from the kinds of value a response or request body is given as.
    • StringStream A readable, seekable PSR-7 stream over a string that is known in full.
    • UnbufferedStream A PSR-7 stream for a body that is still being produced, read once and in order.
    • UploadedFile A PSR-7 file uploaded with a request.
    • Uri A PSR-7 URI.
    • ReadChannelInterface The reading end of a channel: values written to the channel arrive here in the order they were written.
    • RethrowExceptionInterface Marks the exceptions that phasync rethrows with a stack trace that begins in the code that called phasync, not inside it.
    • SelectableInterface An object that can be asked whether using it would block, and waited for until it would not.
    • SubscriberInterface A subscription to a publisher: a reading end that receives every message published after it was made.
    • SubscribersInterface The subscription point of a publisher: each call to subscribe() makes a reader that receives every later message.
    • TimeoutException A wait with a timeout ran out before it was satisfied.
    • Console Terminal output from markup: styled on a terminal, plain text when piped to a file, and laid out the same way in both.
    • ConsoleLogger A PSR-3 logger writing Console::log() lines: to a terminal styled, piped plain.
    • Event A list of listeners that are called when the event is triggered.
    • LockInterface An object that runs a closure while holding a lock that other coroutines wait for.
    • LockTrait Implements LockInterface: a lock that is reentrant for the coroutine holding it and fair for the others.
    • LruCache A bounded in-memory cache that forgets the least recently used entries first.
    • Pool A pool of interchangeable resources, of which only so many may exist at once.
    • Process Starts a child process whose standard streams are used from coroutines without blocking the others.
    • ProcessInterface A child process started with Process::run(), with its standard streams usable from coroutines.
    • ProcessRunner The implementation behind Process::run(): starts a child process and controls it.
    • Queue A first-in first-out queue whose operations take a lock, so coroutines may share it.
    • QueueInterface A first-in first-out queue that coroutines may share.
    • RateLimiter Lets events pass at a fixed rate, shared by every coroutine that calls wait().
    • StringBuffer A buffer of streamed bytes that one coroutine fills and another reads, for parsing protocols that arrive in frames.
    • Synchronized A mutex for coroutines, identified by a string or an object: only one coroutine at a time runs a closure for the same token.
    • WaitGroup Waits until a counted amount of work has been done, like Go's sync.WaitGroup.
    • WriteChannelInterface The writing end of a channel: write() sends a value to the readers of the channel.
    • file_get_contents Reads a whole file, letting other coroutines run while it waits.
    • file_put_contents Writes a file, letting other coroutines run while it waits.
    • flock Locks a file, letting other coroutines run while it waits for the lock.
    • sleep Suspends the current coroutine for $seconds seconds, letting the others run.

    Other packages

    • Channel Pass values between coroutines with phasync::channel(): a read waits for a writer, a write into a full channel waits for a reader.
