    phasync::writable Method

    Suspends the coroutine until the stream can be written without blocking, and returns the stream.

    Description

    public static phasync::writable(mixed $resource, float $timeout = PHP_FLOAT_MAX): mixed

    As phasync::readable does for reading. One coroutine at a time may wait to write to a stream, while another waits to read from it.

    stream_set_blocking($socket, false);
$written = fwrite(phasync::writable($socket), $data);   // may write less than all of $data

    Defined in phasync.

    Parameters

    $resource mixed
    a stream
    $timeout float default PHP_FLOAT_MAX
    seconds to wait at most

    Return values

    $resource, for use in the call that writes it mixed

    Errors / Exceptions

    IOException
    If $resource is not an open stream, or is closed while waiting
    LogicException
    If another coroutine is waiting to write to $resource
    TimeoutException
    If the stream is not writable in time

    See also

    • phasync::readable Suspends the coroutine until the stream can be read without blocking, and returns the stream.
