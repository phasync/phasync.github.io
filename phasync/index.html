    phasync Class

    The static API of phasync: start coroutines, wait for them, cancel them, and wait for streams, flags and contexts.

    Description

    final class phasync

    A coroutine is a closure that runs as a PHP Fiber in the event loop of the process. It runs until it waits (sleep(), yield(), await(), readable(), writable(), awaitFlag(), a channel operation), and then the loop runs another. Code that never waits holds up every other coroutine. A wait looks like a plain function call: it returns a value or throws, so a coroutine reads top to bottom. With the optional phasync-ext extension, blocking PHP functions wait in the same way; phasync behaves the same with and without it.

    run() starts the loop and returns when every coroutine it started has ended; go() starts a coroutine inside it. Every coroutine belongs to a context (any object), and run() does not return before the coroutines of its context have ended. A coroutine that throws, with nobody awaiting it, fails its run().

    A wait takes a timeout in seconds and throws a TimeoutException when it passes; without one it waits for as long as it takes. cancel() throws a CancelledException into a coroutine, so its finally blocks run. To build a wait of your own, park the coroutine with awaitFlag() and wake it with raiseFlag().

    phasync::run(function () {
    $a = phasync::go(function () { phasync::sleep(0.2); return 'a'; });
    $b = phasync::go(function () { phasync::sleep(0.1); return 'b'; });

    echo phasync::await($a), phasync::await($b), "\n";   // ab, after 0.2 seconds, not 0.3
});

    Defined in phasync, package phasync/phasync.

    Methods

    • phasync::run Runs $fn as a coroutine and returns its result once it and every coroutine started inside it have ended.
    • phasync::go Starts $fn as a coroutine in the current context and returns it, without waiting for it.
    • phasync::service Starts $coroutine as a service: a coroutine that belongs to no context, so that it outlives the scope that started it.
    • phasync::await Waits for a coroutine or a promise, and returns its result or throws the exception it ended with.
    • phasync::finally Registers $fn to run when the current coroutine ends, or when the withContext() call it is in returns.
    • phasync::cancel Cancels a coroutine, or every coroutine of a context, with a CancelledException.
    • phasync::throw Interrupts the wait of a suspended coroutine with $exception, once.
    • phasync::sleep Pauses the current coroutine for $seconds, and lets the others run meanwhile.
    • phasync::yield Suspends the current coroutine until the loop has made its next round, after the coroutines that were ready have run.
    • phasync::readable Suspends the coroutine until the stream can be read without blocking, and returns the stream.
    • phasync::writable Suspends the coroutine until the stream can be written without blocking, and returns the stream.
    • phasync::channel Creates a channel and returns its two ends in $read and $write.
    • phasync::publisher Creates a publisher: what is written to $publisher is delivered to every subscription of $subscribers.
    • phasync::raiseFlag Wakes every coroutine waiting for $signal in phasync::awaitFlag, and returns how many it woke.
    • phasync::awaitFlag Suspends the current coroutine until $signal is raised with phasync::raiseFlag.
    • phasync::awaitContext Waits until every coroutine of $context, and of the contexts nested in it, has ended.
    • phasync::isRunning Returns true while a phasync::run is in progress, and false otherwise.
    • phasync::withContext Runs $fn in the current coroutine as the main coroutine of a run() of $context, without starting a coroutine.
    • phasync::getLoop Returns the event loop, for code that waits with its low-level API (getSlot(), park() and unpark() of the returned object).
    • phasync::getFiber Returns the running coroutine.
    • phasync::getRootContext Returns the root context of the running coroutine.
    • phasync::getContext Returns the context of the running coroutine: the object given to run(), go() or withContext(), or the one it inherited.
