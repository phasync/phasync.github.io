    phasync Class Draft

    This class defines the essential API for all coroutine based applications.

    Description

    final class phasync

    This basic API enables implementing all forms of asynchronous programming, including asynchronous CURL and database connections efficiently via the use of flag signals phasync::raiseFlag() and phasync::awaitFlag().

    The essential functions are:

    • phasync::sleep() to pause the coroutine and avoid wasting CPU cycles if there is nothing to do.
    • phasync::readable() and phasync::writable() to pause the coroutine until a stream resource becomes readable or writable.
    • phasync::raiseFlag() and phasync::awaitFlag() to pause the coroutine until an trigger occurs.

    It is bad practice for any advanced functionality to check for external events on every tick, so it should use sleep(), readable(), writable() or raiseFlag()/awaitFlag() to block between each poll.

    For example, to monitor curl handles using multi_curl, a separate coroutine would be launched using phasync::go() which will invoke curl_multi_exec(). It should invoke phasync::sleep(0.1) or so, to avoid busy loops and ideally a single such service coroutine manages all the curl handles across the application. Fibers that need notification would invoke phasync::awaitFlag($curlHandle) and the manager coroutine would invoke phasync::raiseFlag($curlHandle) when the $curlHandle is done.

    Defined in phasync, package phasync/phasync.

    Methods

    • phasync::run Register a coroutine/Fiber to run in the event loop and await the result.
    • phasync::go Creates a normal coroutine and starts running it.
    • phasync::service Launches a service coroutine independently of the context scope.
    • phasync::await Wait for a coroutine, a promise, or a SelectableInterface to complete and return the result.
    • phasync::finally Schedule a closure to run when the current coroutine completes, or, when called inside `phasync::withContext()`, as that call returns, whichever comes first.
    • phasync::cancel Cancel a coroutine, or every coroutine of a context.
    • phasync::throw Interrupt the wait of a suspended coroutine with an exception, once.
    • phasync::sleep Yield time so that other coroutines can continue processing.
    • phasync::yield Suspend the fiber until immediately after some other fibers has performed work.
    • phasync::readable Suspend the coroutine until the stream can be read without blocking: data arrived, the peer finished, or the stream failed.
    • phasync::writable Suspend the coroutine until the stream can be written without blocking, as `phasync::readable()` does for reading.
    • phasync::channel Creates a channel pair which can be used to communicate between multiple coroutines.
    • phasync::publisher A publisher works like channels, but supports many subscribing coroutines concurrently.
    • phasync::raiseFlag Signal all coroutines that are waiting for an event represented by the object $signal to resume.
    • phasync::awaitFlag Pause execution of the current coroutine until an event is signalled represented by the object $signal.
    • phasync::awaitContext Wait until every coroutine of $context, and of the contexts nested in it, has ended; a server that lets requests start coroutines of their own waits for them this way before it exits.
    • phasync::isRunning Returns true when called from within a coroutine context.
    • phasync::withContext Run $fn in the current coroutine as if it were the main coroutine of a phasync::run() of $context, without starting a coroutine, which costs far more: it returns what $fn returns, once the coroutines $fn started in the context have ended too.
    • phasync::getLoop The event loop, for code that waits with its low-level API (`EventLoop::park()`).
    • phasync::getFiber Get the currently running coroutine.
    • phasync::getRootContext The root context of the running coroutine: its request, so to say.
    • phasync::getContext The context of the running coroutine: the object given to run(), go() or withContext(), or the one it inherited.

    Examples#

    phasync::run(function () {
    $a = phasync::go(function () { phasync::sleep(0.2); return 'a'; });
    $b = phasync::go(function () { phasync::sleep(0.1); return 'b'; });

    echo phasync::await($a), phasync::await($b), "\n";   // ab, after 0.2 seconds
});

    Notes#

    • phasync is a final class of static methods in the global namespace.
    • The package is phasync/phasync. It behaves the same with and without the phasync-ext extension, which lets more code wait without blocking and makes waiting cheaper.
