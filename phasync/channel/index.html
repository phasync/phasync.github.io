    phasync::channel Method

    Creates a channel pair which can be used to communicate between multiple coroutines.

    Description

    public static phasync::channel(
    ?ReadChannelInterface &$read,
    ?WriteChannelInterface &$write,
    int $bufferSize = 0
): void

    Channels should be used to pass serializable data, to support passing channels to worker processes, but it is possible to pass more complex data if you are certain the data will not be passed to other processes.

    If a function is passed in either argument, it will be run a coroutine with the ReadChannelInterface or the WriteChannelInterface as the first argument.

    Defined in phasync.

    Parameters

    $read ?ReadChannelInterface
    $write ?WriteChannelInterface
    $bufferSize int default 0

    Return values

    No value is returned.
