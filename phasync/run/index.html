    phasync::run Method Draft

    Register a coroutine/Fiber to run in the event loop and await the result.

    Description

    public static phasync::run(Closure $fn, ?array $args = [], ?object $context = null): mixed

    Running a coroutine this way also ensures that the event loop will run until all nested coroutines have completed. If you want to create a coroutine inside this context, and leave it running after - the coroutine must be created from within another coroutine outside of the context, for example by using a Channel.

    Defined in phasync.

    Parameters

    $fn Closure
    $args ?array default []
    $context ?object default null

    Return values

    Returns mixed.

    Errors / Exceptions

    FiberError
    Throwable

    Examples#

    $result = phasync::run(function () {
    return 'done';
});
echo $result;     // done

    run() returns when the function and every coroutine started inside it have ended:

    phasync::run(function () {
    phasync::go(function () {
        phasync::sleep(0.1);
        echo "second\n";
    });
    echo "first\n";
});
echo "third\n";

    Notes#

    • Inside Swerve, a request is already served in a run() of its own. You call run() in a library, a script or a test, where nothing has started the loop yet.
    • Called from inside a coroutine, it runs the function as a coroutine in the same event loop.
    • An exception thrown in the function is thrown from run().

    See also

    • phasync::go Creates a normal coroutine and starts running it.
    • phasync::sleep Yield time so that other coroutines can continue processing.
