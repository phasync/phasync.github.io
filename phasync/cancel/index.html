    phasync::cancel Method

    Cancel a coroutine, or every coroutine of a context.

    Description

    public static phasync::cancel(
    object $fiber,
    Stringable|string $message = 'Operation cancelled',
    int $code = 0,
    ?Throwable $previous = null
): void

    The cancellation is sticky: the coroutine's waits throw a CancelledException until it ends (or leaves the context), so that a coroutine which catches it and waits again is cancelled again. It is a teardown, not a signal: to interrupt a wait once with an exception of your own, use phasync::throw().

    Given a context, cancels every waiting coroutine of it and of the contexts nested in it, the deepest first, except the calling coroutine.

    Defined in phasync.

    Parameters

    $fiber object
    $message Stringable|string default 'Operation cancelled'
    The message of the CancelledException; a Throwable is refused, see {@see phasync::throw()}
    $code int default 0
    The code of the CancelledException
    $previous ?Throwable default null
    What caused the cancellation, such as the failure that tears a context down

    Return values

    No value is returned.

    Errors / Exceptions

    InvalidArgumentException
    If the fiber is terminated, or the message is a Throwable
