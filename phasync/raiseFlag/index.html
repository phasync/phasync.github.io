    phasync::raiseFlag Method

    Wakes every coroutine waiting for $signal in phasync::awaitFlag, and returns how many it woke.

    Description

    public static phasync::raiseFlag(object $signal): int

    A flag is any object: the one the waiters and the raiser share is the signal. Raising a flag nobody waits for does nothing, and is not remembered. This and awaitFlag() are what the other waits of phasync are built on.

    phasync::run(function () {
    $ready = new stdClass();
    phasync::go(function () use ($ready) {
        phasync::awaitFlag($ready);
        echo "ready\n";
    });
    echo phasync::raiseFlag($ready), " woken\n";   // 1 woken
});

    Defined in phasync.

    Parameters

    $signal object
    the object the waiters wait for

    Return values

    The number of coroutines woken int
