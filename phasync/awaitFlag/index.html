    phasync::awaitFlag Method

    Suspends the current coroutine until $signal is raised with phasync::raiseFlag.

    Description

    public static phasync::awaitFlag(object $signal, float $timeout = PHP_FLOAT_MAX): void

    The wait does not keep $signal alive: hold a reference to it elsewhere for as long as the coroutine waits. When the last other reference goes, the coroutine is woken with a CancelledException, because nothing can raise the flag any more. Waiting on an object nothing else references is undefined.

    $done = new stdClass();
phasync::go(function () use ($done) {
    phasync::sleep(0.1);
    phasync::raiseFlag($done);
});
phasync::awaitFlag($done, 1.0);   // returns after 0.1 seconds

    Defined in phasync.

    Parameters

    $signal object
    the object a raiser will pass to raiseFlag()
    $timeout float default PHP_FLOAT_MAX
    seconds to wait at most

    Return values

    No value is returned.

    Errors / Exceptions

    TimeoutException
    If the flag is not raised in time
    CancelledException
    If the flag was released while waiting
    LogicException
    Outside a coroutine

    See also

    • phasync::raiseFlag Wakes every coroutine waiting for $signal in phasync::awaitFlag, and returns how many it woke.
