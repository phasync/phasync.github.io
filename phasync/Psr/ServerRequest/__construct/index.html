    phasync\Psr\ServerRequest::__construct Method

    Creates a server request.

    Description

    public ServerRequest::__construct(
    string $method,
    string $requestTarget,
    mixed $body,
    array $headers = [],

    array $serverParams = [],
    array $cookieParams = [],

    A Closure given for the body, the uploaded files or the parsed body is called each time that is asked for, until a with...() method replaces it: a server can parse the body on demand, and every clone sees the same state.

    Defined in phasync\Psr\ServerRequest.

    request target, e.g. "/path?query=value"
    $body mixed

    array of header names => values
    $queryParams ?array default null

    $attributes array default []
