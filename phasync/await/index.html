    phasync::await Method

    Waits for a coroutine or a promise, and returns its result or throws the exception it ended with.

    Description

    public static phasync::await(
    object $fiberOrPromise,
    float $timeout = PHP_FLOAT_MAX
): mixed

    A coroutine can be awaited any number of times, by any number of coroutines, and each call returns the same value or throws the same exception. Awaiting a failed coroutine counts as handling its failure: it no longer fails the run. A timeout throws in the caller only: the awaited coroutine keeps running.

    Given a SelectableInterface (a channel end, a WaitGroup, a StringBuffer, a RateLimiter), it waits until the object isReady() and returns the object. How a timeout ends depends on the object, see its await(). Given an object with a then() method, such as a promise from another library, it waits until the promise settles, and returns its value or throws its rejection; a rejection that is not a Throwable is thrown as an Exception with its string form as message.

    phasync::run(function () {
    $fiber = phasync::go(function () { phasync::sleep(0.1); return 'result'; });

    try {
        phasync::await($fiber, 0.01);
    } catch (phasync\TimeoutException) {
        echo "not yet\n";
    }
    echo phasync::await($fiber), "\n";   // result
});

    Defined in phasync.

    Parameters

    $fiberOrPromise object
    a coroutine from go() or run(), a SelectableInterface, or a promise-like object
    $timeout float default PHP_FLOAT_MAX
    seconds to wait at most

    Return values

    The coroutine's return value; for a SelectableInterface, the object mixed

    Errors / Exceptions

    TimeoutException
    If a coroutine or promise does not end within $timeout
    InvalidArgumentException
    For an object that is none of the above
    LogicException
    For a Fiber that phasync did not start
    Throwable
    What the coroutine threw

    See also

    • phasync::go Starts $fn as a coroutine in the current context and returns it, without waiting for it.
    • phasync::cancel Cancels a coroutine, or every coroutine of a context, with a CancelledException.
    • phasync::awaitContext Waits until every coroutine of $context, and of the contexts nested in it, has ended.
