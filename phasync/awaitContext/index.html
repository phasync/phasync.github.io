    phasync::awaitContext Method

    Waits until every coroutine of $context, and of the contexts nested in it, has ended.

    Description

    public static phasync::awaitContext(object $context, float $timeout = PHP_FLOAT_MAX): void

    A server that lets requests start coroutines of their own waits for them this way before it exits. Coroutines started in the meantime are waited for too. Nothing is thrown for their failures: those go where they always go, see phasync::run. The calling coroutine does not wait for itself.

    phasync::run(function () {
    $context = new stdClass();
    phasync::go(function () { phasync::sleep(0.1); echo "ended\n"; }, [], $context);

    phasync::awaitContext($context);
    echo "all ended\n";
});

    Defined in phasync.

    Parameters

    $context object
    a context given to run(), go() or withContext()
    $timeout float default PHP_FLOAT_MAX
    seconds to wait at most

    Return values

    No value is returned.

    Errors / Exceptions

    LogicException
    Outside a coroutine
    TimeoutException
    If coroutines of the context still run after $timeout seconds

    See also

    • phasync::cancel given a context, cancels its coroutines
    • phasync::withContext Runs $fn in the current coroutine as the main coroutine of a run() of $context, without starting a coroutine.
