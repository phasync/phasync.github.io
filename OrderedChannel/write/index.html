    OrderedChannel::write Method

    Append $message to the channel, where every subscriber receives it in the channel's one order.

    Description

    public OrderedChannel::write(mixed $message): void

    The message is encoded as Swerve::publish does. While the channel has no subscriber anywhere nothing is written and the message is dropped.

    $ledger = new OrderedChannel('ledger');
$ledger->write(['debit', 12]);

    Defined in Swerve\OrderedChannel.

    Parameters

    $message mixed
    anything json_encode() takes except null; at most 128 KiB encoded

    Return values

    No value is returned.

    Errors / Exceptions

    InvalidArgumentException
    As Swerve::publish() does, and for a name starting with "\0"
    LogicException
    While the application loads: the worker serves after that
    JsonException
    For a value JSON can't express

    See also

    • OrderedChannel::subscribe Receive what is written from now on, as Swerve::subscribe does.
    • Swerve::publish Send a message to every subscriber of $topic, in every worker process of this swerve, this one included.
