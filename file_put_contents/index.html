    file_put_contents Function

    Writes a file, letting other coroutines run while it waits.

    Description

    function file_put_contents(string $filename, mixed $data, int $flags = 0): int|false

    Inside a coroutine, it truncates the file (or appends, with FILE_APPEND) and writes $data with phasync::writable() between the writes. Outside one, it is the native file_put_contents(). Only FILE_APPEND and LOCK_EX of the native flags are handled.

    A stream resource as $data fails inside a coroutine with a TypeError, after the file was truncated.

    use function phasync\file_put_contents;

file_put_contents('/tmp/log.txt', "started\n", FILE_APPEND);

    Defined in phasync\file_put_contents, package phasync/phasync.

    Parameters

    $filename string
    the file to write
    $data mixed
    a string, or an array of strings that are joined
    $flags int default 0
    FILE_APPEND and LOCK_EX

    Return values

    The number of bytes written int|false

    Errors / Exceptions

    Exception
    When the file cannot be opened
    RuntimeException
    When a write fails
