    RateLimiter Class

    Lets events pass at a fixed rate, shared by every coroutine that calls wait().

    Description

    final class RateLimiter implements SelectableInterface

    The constructor starts a coroutine in the current context that issues one permit every 1 / $eventsPerSecond seconds, and it stops when the limiter is dropped. The first wait() returns at once. A $burst above 0 lets permits accumulate while nobody waits: after an idle period, up to $burst + 1 events pass at once. A limiter is a SelectableInterface: it is ready when a permit is available.

    phasync::run(function () {
    $limiter = new phasync\Util\RateLimiter(10);

    for ($i = 0; $i < 5; $i++) {
        $limiter->wait();
        echo "at most 10 per second\n";
    }
});

    Defined in phasync\Util\RateLimiter, package phasync/phasync.

    Methods

    • RateLimiter::__construct Creates the limiter and starts its coroutine.
    • RateLimiter::await Waits for a permit and takes it.
    • RateLimiter::isReady Returns true if a permit is available.
    • RateLimiter::wait Waits for a permit, which delays the coroutine as much as the rate requires.

    See also

    • SelectableInterface An object that can be asked whether using it would block, and waited for until it would not.
    • phasync::sleep Pauses the current coroutine for $seconds, and lets the others run meanwhile.
