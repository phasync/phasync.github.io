    BufferedStream Class

    A seekable PSR-7 stream for a body that is still being produced, kept in memory and then in a temporary file.

    Description

    class BufferedStream implements StreamInterface, \Stringable

    One coroutine appends with BufferedStream::append and ends with BufferedStream::end. Content is kept in memory up to $bufferSize bytes, and then moved to a temporary file. Nothing is discarded when it has been read, so memory or disk use grows with the content; use UnbufferedStream for a body that is not needed after it was read. getSize() waits until end().

    Known limitation: after end(), read(), seek() and getContents() throw a LogicException ("No updates will occur in an ended stream"), so the content has to be read before end() is called.

    $stream = new BufferedStream();

phasync::go(function () use ($stream) {
    $stream->append('A chunk');
    $stream->end();
});

$size = $stream->getSize();   // waits for end(): 7

    Defined in phasync\Psr\BufferedStream, package phasync/phasync.

    • BufferedStream::__construct Creates an empty stream.
    • BufferedStream::__toString Returns the content from the start, or a message starting with "Stream Error" when that fails.
    • BufferedStream::close Closes the stream and any underlying resources.
    • BufferedStream::detach Separates any underlying resources from the stream.
    • BufferedStream::getSize Get the size of the stream if known.
    • BufferedStream::tell Returns the current position of the file read/write pointer
    • BufferedStream::eof Returns true if the stream is at the end of the stream.
    • BufferedStream::isSeekable Returns whether or not the stream is seekable.
    • BufferedStream::seek Seek to a position in the stream.
    • BufferedStream::rewind Seek to the beginning of the stream.
    • BufferedStream::isWritable Returns whether or not the stream is writable.
    • BufferedStream::write Write data to the stream.
    • BufferedStream::isReadable Returns whether or not the stream is readable.
    • BufferedStream::read Read data from the stream.
    • BufferedStream::getContents Returns the remaining contents in a string
    • BufferedStream::getMetadata Get stream metadata as an associative array or retrieve a specific key.
    • BufferedStream::append Adds $chunk to the end of the stream, without waiting for a reader.
    • BufferedStream::end Declares that nothing more will be appended, which fixes the size of the stream.
