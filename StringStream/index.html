    StringStream Class

    A readable, seekable PSR-7 stream over a string that is known in full.

    Description

    class StringStream implements StreamInterface, \Stringable

    Never blocks. StreamFactory::create returns one for a string body.

    $stream = new StringStream('Hello');
$stream->read(2);        // "He"
$stream->getSize();      // 5

    Defined in phasync\Psr\StringStream, package phasync/phasync.
