    SubscriberInterface Interface

    A subscription to a publisher: a reading end that receives every message published after it was made.

    Description

    interface SubscriberInterface extends ReadChannelInterface, \IteratorAggregate, \Traversable, SelectableInterface

    It is read like any ReadChannelInterface, with read() or foreach. A subscription that falls behind does not hold the publisher or the other subscriptions back, and it ends once the publisher is closed and its messages are read.

    phasync::run(function () {
    phasync::publisher($subscribers, $publisher);
    $subscription = $subscribers->subscribe();

    phasync::go(function () use ($publisher) {
        $publisher->write('a');
        $publisher->write('b');
        $publisher->close();
    });

    foreach ($subscription as $message) {
        echo $message, "\n";      // a, then b
    }
});

    Defined in phasync\SubscriberInterface, package phasync/phasync.

    See also

    • phasync::publisher Creates a publisher: what is written to $publisher is delivered to every subscription of $subscribers.
    • SubscribersInterface::subscribe Creates a subscription that receives the messages published after this call.
