    ConsoleLogger Class

    A PSR-3 logger writing Console::log() lines: to a terminal styled, piped plain.

    Description

    final class ConsoleLogger implements LoggerInterface
    $logger = new ConsoleLogger();                                  // STDERR, every level
$logger = new ConsoleLogger(new Console(STDOUT), 'warning');    // warning and up
$logger->error('disk {path} is full', ['path' => '/var']);

    It satisfies psr/log 1, 2 and 3 alike: untyped parameters where earlier versions have them, void returns as 3 requires.

    Defined in phasync\Util\ConsoleLogger, package phasync/phasync.

    Methods

    • ConsoleLogger::__construct Creates a logger.
    • ConsoleLogger::log Logs with an arbitrary level.
    • ConsoleLogger::emergency System is unusable.
    • ConsoleLogger::alert Action must be taken immediately.
    • ConsoleLogger::critical Critical conditions.
    • ConsoleLogger::error Runtime errors that do not require immediate action but should typically be logged and monitored.
    • ConsoleLogger::warning Exceptional occurrences that are not errors.
    • ConsoleLogger::notice Normal but significant events.
    • ConsoleLogger::info Interesting events.
    • ConsoleLogger::debug Detailed debug information.
