This path installs [Swerve](/swerve/), an application server built on phasync, and walks through running
and deploying an application on it: the quickest way to see phasync run a whole application, not only
phasync on its own. Nothing here assumes you know phasync; every page starts with the command to type.
To add phasync to code that already runs under PHP-FPM instead, without a server to install, see
[Use phasync in a library](/library/use-phasync-in-a-library/).
