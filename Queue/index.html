    Queue Class

    A first-in first-out queue whose operations take a lock, so coroutines may share it.

    Description

    class Queue implements QueueInterface, LockInterface, \Countable

    Nothing here waits for a value: tryDequeue() returns false when the queue is empty. To wait for values, use a channel.

    $queue = new phasync\Util\Queue();
$queue->enqueue('a');
$queue->enqueue('b');

$queue->tryDequeue($value);   // $value is 'a'
echo count($queue), "\n";     // 1

    Defined in phasync\Util\Queue, package phasync/phasync.

    Methods

    • Queue::__construct Creates an empty queue.
    • Queue::isEmpty Returns true if the queue holds no values.
    • Queue::enqueue Adds $value at the end of the queue.
    • Queue::tryDequeue Takes the first value off the queue into $value, and returns whether there was one.
    • Queue::tryPeek Copies the first value of the queue into $value, without removing it, and returns whether there was one.
    • Queue::count Returns the number of values in the queue.
    • Queue::lock Runs $callable while holding the lock of this object, and returns what it returns.

    See also

    • phasync::channel to wait for values
    • LockInterface An object that runs a closure while holding a lock that other coroutines wait for.
