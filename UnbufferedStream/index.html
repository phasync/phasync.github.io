    UnbufferedStream Class

    A PSR-7 stream for a body that is still being produced, read once and in order.

    Description

    class UnbufferedStream implements StreamInterface, \Stringable

    One coroutine appends with UnbufferedStream::append and ends with UnbufferedStream::end; another reads. read() waits while there is nothing to read and the stream is not ended, and append() waits while more than $bufferSize bytes are unread. The stream is not seekable or writable, and getSize() is null.

    Both sides wait with phasync::awaitFlag(): after $deadlockTimeout seconds without the other side making progress, the waiting call throws a TimeoutException.

    The coroutine that created the stream cannot convert it to a string: __toString() returns an error message instead of waiting for itself.

    $stream = new UnbufferedStream();

phasync::go(function () use ($stream) {
    foreach (['one', 'two', 'three'] as $chunk) {
        $stream->append($chunk . "\n");
        phasync::sleep(0.1);
    }
    $stream->end();
});

// A server sends this body to the client, reading it from another coroutine
$response = $response->withBody($stream);

    Defined in phasync\Psr\UnbufferedStream, package phasync/phasync.

    Methods

    • UnbufferedStream::__construct Creates an empty stream, owned by the current coroutine.
    • UnbufferedStream::__toString Returns the rest of the stream, or a message starting with "Stream Error" when it cannot: it was closed or detached, or this is the coroutine that created the stream.
    • UnbufferedStream::close Discards the unread content.
    • UnbufferedStream::detach Separates any underlying resources from the stream.
    • UnbufferedStream::getSize Get the size of the stream if known.
    • UnbufferedStream::tell Returns the current position of the file read/write pointer
    • UnbufferedStream::eof Returns true if the stream is at the end of the stream.
    • UnbufferedStream::isSeekable Returns whether or not the stream is seekable.
    • UnbufferedStream::seek Seek to a position in the stream.
    • UnbufferedStream::rewind Seek to the beginning of the stream.
    • UnbufferedStream::isWritable Returns whether or not the stream is writable.
    • UnbufferedStream::write Write data to the stream.
    • UnbufferedStream::isReadable Returns whether or not the stream is readable.
    • UnbufferedStream::read Read data from the stream.
    • UnbufferedStream::getContents Returns the remaining contents in a string
    • UnbufferedStream::getMetadata Get stream metadata as an associative array or retrieve a specific key.
    • UnbufferedStream::append Adds $chunk to the end of the stream.
    • UnbufferedStream::end Declares that nothing more will be appended, which lets a reader reach the end of the stream.
