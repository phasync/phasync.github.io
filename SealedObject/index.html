    SealedObject Class

    A decoded JSON object that nobody can change: what a subscriber of Swerve::subscribe gets for a published object.

    Description

    final class SealedObject implements \IteratorAggregate, \JsonSerializable, \Traversable

    The message is decoded once per worker and shared by all its subscribers, which are coroutines; a plain stdClass would let one attach a property, or change one, for all the others to see. Nested objects are SealedObjects too.

    foreach (Swerve::subscribe('game') as $message) {
    if ($message instanceof SealedObject && isset($message->end)) {   // a property
        break;
    }
    foreach ($message as $name => $value) { ... }                     // iterable
}

    Reading a missing property triggers a warning and gives null. Assigning or unsetting throws a LogicException. json_encode() gives the object back as it was published.

    Defined in Swerve\Util\SealedObject, package phasync/swerve.

    Methods

    • SealedObject::__construct Wrap a decoded object; SealedObject::seal does it for a whole decoded value.
    • SealedObject::seal What json_decode() (without assoc) returned, with its objects replaced by SealedObjects; the objects inside one are wrapped when first read.
    • SealedObject::__get The property $name; an object in it is a SealedObject.
    • SealedObject::__isset Whether the property exists and is not null.
    • SealedObject::__set Always throws: the message is shared by every subscriber.
    • SealedObject::__unset Always throws: the message is shared by every subscriber.
    • SealedObject::getIterator The properties by name; objects in them are SealedObjects.
    • SealedObject::jsonSerialize A copy of the object as it was published, for json_encode().

    See also

    • Swerve::publish Send a message to every subscriber of $topic, in every worker process of this swerve, this one included.
    • Swerve::subscribe Receive what is published to $topic from now on.
