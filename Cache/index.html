    Cache Class

    The cache every worker shares, from Swerve::cache(): a PSR-16 cache held by the master process, the least recently used entries evicted past --cache-size.

    Description

    final class Cache implements CacheInterface
    $cache = Swerve::cache();
$user  = $cache->get("user:$id") ?? load_user($id);
$cache->set("user:$id", $user, 60);

    Two layers. Each worker keeps what it read (and what it found missing) in a local layer of LOCAL_BYTES, so a repeated read costs no trip to the master. Writes go to the master, which then tells every worker, the writer included, to forget those keys; it sends no values, a worker fetches a value when it next reads it. The master's messages to a worker arrive in the order it sent them, and a worker stores what it fetched as it reads the reply, so a worker never keeps a value older than the last write it was told of. A trip to the master costs about 0.1 ms, during which only the calling coroutine waits.

    Values are serialized in the worker; the master keeps the strings and never unserializes them, so application classes never load there. An entry with a TTL expires at the same moment in every layer (the monotonic clock is the machine's). The contents last as long as the master: a rolling reload keeps them, a restart empties them. Without a master (the application served by something other than swerve's workers), the cache is the process's own.

    It needs the master, so a read that has to ask it, and every write, throw a LogicException while swerve.php loads: the worker serves after that. A key is a non-empty string without {}()/\@:, else a CacheKeyException is thrown.

    Defined in Swerve\Cache, package phasync/swerve.

    Constants

    LOCAL_BYTES = 8388608
    Bytes of a worker's local layer.

    Properties

    $listening static bool
    Set once the worker reads its pipe: before that no reply could arrive.

    Methods

    • Cache::instance The cache of this process: the one Swerve::cache returns.
    • Cache::get The value stored under $key, or $default when there is none or it has expired.
    • Cache::getMultiple The values of $keys, by key: $default for those missing or expired.
    • Cache::has Whether a value is stored under $key and has not expired.
    • Cache::set Store $value under $key for every worker, for $ttl seconds or until evicted.
    • Cache::setMultiple Store several values, by key, with one $ttl, as Cache::set does.
    • Cache::delete Remove $key from the cache of every worker.
    • Cache::deleteMultiple Remove several keys, as Cache::delete does.
    • Cache::clear Remove everything from the cache of every worker.

    See also

    • Swerve::cache The cache every worker shares, held by the master process.
    • Swerve::claim A handle on the name $name, which one holder at a time can hold across the workers.
    • CacheKeyException A key Swerve::cache can't take: PSR-16 keys are non-empty strings without {}()/\@:.
