    ReadChannelInterface Interface

    The reading end of a channel: values written to the channel arrive here in the order they were written.

    Description

    interface ReadChannelInterface extends SelectableInterface, \Traversable

    Any PHP value can be sent, because a channel is in-memory communication between coroutines of one process and nothing is serialized. read() waits while the channel is empty, foreach over the end reads until the channel is closed and empty, and each value goes to exactly one reader. Closing either end closes the channel, and so does dropping the last reference to either end; values already written can still be read.

    phasync::run(function () {
    phasync::channel($read, $write);

    phasync::go(function () use ($write) {
        $write->write('hello');
        $write->close();
    });

    foreach ($read as $message) {
        echo $message, "\n";       // hello
    }
});

    Defined in phasync\ReadChannelInterface, package phasync/phasync.

    Methods

    • ReadChannelInterface::activate Switches off the deadlock check of the channel.
    • ReadChannelInterface::close Closes the channel, for both ends.
    • ReadChannelInterface::isClosed Returns true if the channel has been closed, also when values are left to read.
    • ReadChannelInterface::read Returns the next value, and waits while there is none and the channel is open.
    • ReadChannelInterface::isReadable Returns true if the channel is open, or has values left to read.

    See also

    • phasync::channel Creates a channel and returns its two ends in $read and $write.
    • WriteChannelInterface The writing end of a channel: write() sends a value to the readers of the channel.
    • SubscriberInterface when every reader should get every value
