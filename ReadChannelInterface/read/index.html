    ReadChannelInterface::read Method

    Returns the next value, and waits while there is none and the channel is open.

    Description

    public ReadChannelInterface::read(
    float $timeout = PHP_FLOAT_MAX,
    ?bool &$eof = null
): mixed

    null is both a value that can be written and what read() returns when the channel is closed with nothing left, so the return value alone cannot tell them apart. Pass $eof: it is set to true only when the channel is closed and empty, and false otherwise, also when the value is null.

    phasync::run(function () {
    phasync::channel($read, $write, 2);
    $write->write(null);
    $write->close();

    $read->read(eof: $eof);   // null, $eof is false: a value
    $read->read(eof: $eof);   // null, $eof is true: the end
});

    Defined in phasync\ReadChannelInterface.

    Parameters

    $timeout float default PHP_FLOAT_MAX
    seconds to wait at most
    $eof ?bool default null
    set to true if the channel is closed and empty

    Return values

    The value, or null at the end of the channel mixed

    Errors / Exceptions

    TimeoutException
    If nothing arrived in time
    ChannelException
    If the creator of the channel waits on it alone, see ReadChannelInterface::activate
