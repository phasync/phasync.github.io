    ReadChannelInterface::read Method

    Returns the next item that can be read.

    Description

    public ReadChannelInterface::read(
    float $timeout = PHP_FLOAT_MAX,
    ?bool &$eof = null
): mixed

    If no item is available and the channel is still open, the function will suspend the coroutine and allow other coroutines to work.

    null is both a legal value (if it was written) and what is returned when the channel is closed with nothing left to read, so the two are not distinguishable from the return value alone. Pass $eof by reference to tell them apart: it is set to true only when the channel is closed and there was nothing left, false otherwise (including when the returned value happens to be null).
