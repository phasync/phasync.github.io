    Console::write Method

    Writes $markup to the stream, styled or plain as the console is.

    Description

    public Console::write(string $markup): void
    $out = new Console();
$out->write("<!bold pad 12>--http<!><!dim>Serve HTTP here<!>\n");

    Defined in phasync\Util\Console.

    Parameters

    $markup string
    text with <!...> spans, see the class description

    Return values

    No value is returned.

    Errors / Exceptions

    InvalidArgumentException
    For a pad, lpad, rpad or center without a width
