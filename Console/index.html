    Console Class

    Terminal output from markup: styled on a terminal, plain text when piped to a file, and laid out the same way in both.

    Description

    final class Console

    <!…> opens a span, <!> closes the last one opened; spans nest. A span takes styles and layout, in any order:

    • colors: black, red, green, yellow, blue, magenta, cyan, white, gray, their bright- variants (bright-red...), and backgrounds bg-<color>; attributes: bold, dim, italic, underline, blink, inverse, strike
    • padding: pad 20 (or rpad 20) makes the span exactly 20 columns, padded on the right; lpad 20 pads on the left; center 20 centers. Longer content is cut with "…", or without it given clip. A width may be a percentage of the terminal's: pad 50%.
    $out = new Console();
$out->write("<!bold pad 12>--http<!><!dim>Serve HTTP here<!>\n");
$out->write("<!lpad 8>1.2 MB<!> <!pad 40>$name<!>\n");

    Text from elsewhere goes through escape() first. Widths count terminal columns: East Asian wide characters and emoji take 2, combining marks and zero-width characters 0.

    Defined in phasync\Util\Console, package phasync/phasync.

    Methods

    • Console::__construct Creates a console writing to $stream.
    • Console::write Writes $markup to the stream, styled or plain as the console is.
    • Console::log Writes a log line, in one format everywhere.
    • Console::render $markup as this console writes it: styled, or plain.
    • Console::hasColor Returns whether this console writes styled output.
    • Console::columns The terminal's width in columns: $COLUMNS, else 80.
    • Console::strip $markup as plain text, laid out.
    • Console::escape $text made safe to embed in markup: shown as it is.
    • Console::width The columns $markup takes on a terminal.
    • Console::pad Returns $markup padded with $pad to $width columns.
    • Console::cut $markup cut to at most $width columns, ending with $ellipsis when anything was cut; the styles still open are closed.
