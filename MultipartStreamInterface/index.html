    MultipartStreamInterface Interface

    A request body stream that carries a multipart/form-data payload.

    Description

    interface MultipartStreamInterface extends StreamInterface, \Stringable

    HttpClient::sendRequest sends self::getContentType(), boundary included, as the Content-Type header of a request whose body implements this interface, so the caller sets none. Implement it for a body that is built elsewhere than MultipartStream.

    $body = new MultipartStream(['title' => 'Report', 'file' => \fopen('report.pdf', 'r')]);
$client->post('https://example.com/upload', $body); // Content-Type: $body->getContentType()

    Defined in phasync\HttpClient\MultipartStreamInterface, package phasync/http-client.

    Methods

    • MultipartStreamInterface::getContentType Return the value of the Content-Type header, with the boundary parameter.
