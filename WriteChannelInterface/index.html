    WriteChannelInterface Interface

    The writing end of a channel: write() sends a value to the readers of the channel.

    Description

    interface WriteChannelInterface extends SelectableInterface

    On an unbuffered channel write() returns when a reader has taken the value; on a buffered one it returns at once while the buffer has room, and waits when it is full. Dropping the last reference to an end closes the channel, so a reader sees the end when the writer is gone.

    phasync::run(function () {
    phasync::channel($read, $write, 3);

    phasync::go(function () use ($write) {
        foreach ([1, 2, 3] as $number) {
            $write->write($number);
        }
        $write->close();
    });

    foreach ($read as $number) {
        echo $number, "\n";
    }
});

    Defined in phasync\WriteChannelInterface, package phasync/phasync.

    Methods

    • WriteChannelInterface::activate Switches off the deadlock check of the channel.
    • WriteChannelInterface::close Closes the channel, for both ends.
    • WriteChannelInterface::isClosed Returns true if the channel has been closed.
    • WriteChannelInterface::write Sends a value, and waits while the channel cannot take it: for a reader on an unbuffered channel, for room on a full buffer.
    • WriteChannelInterface::isWritable Returns true if the channel is open, so a write is accepted.

    See also
