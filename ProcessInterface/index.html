    ProcessInterface Interface

    A child process started with Process::run(), with its standard streams usable from coroutines.

    Description

    interface ProcessInterface

    read() and write() wait for their stream without blocking the other coroutines. When the process has ended and isRunning() or another status call has noticed it, its streams are closed, so read the output before asking.

    phasync::run(function () {
    $cat = phasync\Util\Process::run('cat');
    $cat->write("ping\n");
    echo $cat->read();            // ping
    $cat->stop();
});

    Defined in phasync\Util\ProcessInterface, package phasync/phasync.

    Constants

    STDIN = 0
    STDOUT = 1
    STDERR = 2

    Methods

    • ProcessInterface::stop Ends the process: SIGTERM, then SIGKILL after one second, and waits up to five seconds in all.
    • ProcessInterface::isRunning Returns true if the process is running.
    • ProcessInterface::isStopped Returns true if the process is paused by a stop signal.
    • ProcessInterface::getExitCode Returns the exit code of the process, or false while it runs.
    • ProcessInterface::sendSignal Sends a signal to the process, and returns false without sending it if the process is not running.
    • ProcessInterface::read Waits until the stream has something to read, and returns what is there.
    • ProcessInterface::write Waits until the stream can take data, and writes as much as it takes.
    • ProcessInterface::getStream Returns the stream of a standard descriptor, for stream_select(), phasync::readable() and the like.

    See also

    • Process::run Starts $command in the background and returns the object that controls it.
