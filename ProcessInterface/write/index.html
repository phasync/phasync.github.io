    ProcessInterface::write Method

    Waits until the stream can take data, and writes as much as it takes.

    Description

    public ProcessInterface::write(string $data, int $fd = self::STDIN): int|false

    Defined in phasync\Util\ProcessInterface.

    Parameters

    $data string
    what to write
    $fd int default self::STDIN
    ProcessInterface::STDIN

    Return values

    The number of bytes written, which may be less than all of $data; false if the process is not running int|false

    Errors / Exceptions
